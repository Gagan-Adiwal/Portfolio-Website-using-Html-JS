# 🌐 Personal Portfolio Website  

A **modern, fully responsive portfolio website** built with **HTML, CSS, and JavaScript**.  
This project is designed to showcase **skills, projects, and achievements** in a clean and elegant way.  

---

## ✨ Features  

- 📱 **Responsive Design** – Works smoothly on desktop, tablet, and mobile devices  
- 🎨 **Modern UI/UX** – Clean layout with animations and transitions  
- 🖼️ **Profile Section** – Hero area with name, role, and profile image  
- 📑 **Navigation Bar** – Sticky top navigation with smooth scrolling  
- 💼 **Projects Showcase** – Section to highlight your best work  
- 📜 **Resume Download** – Direct download link for CV  
- 📬 **Contact Section** – Easy way for people to reach you  
- ⚡ **Lightweight & Fast** – Pure HTML, CSS, and JavaScript (no frameworks)  

---

## 🛠️ Tech Stack  

- **HTML5** – Semantic markup  
- **CSS3** – Flexbox, Grid, Animations  
- **JavaScript (ES6)** – Interactivity and smooth scrolling
